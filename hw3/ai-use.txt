### Prompt 1- Help me create database/schema.sql using SQLite.

The AirAsia Requirements Document specifies two tables for HW3:

ACCOUNT:
- accountId: INTEGER PRIMARY KEY, automatically generated
- userId: INTEGER NOT NULL
- accountType: TEXT NOT NULL, maximum 100 characters
- points: INTEGER NOT NULL

GIFTCARD:
- cardId: INTEGER PRIMARY KEY, automatically generated
- cardName: TEXT NOT NULL, maximum 100 characters
- cardType: TEXT NOT NULL, maximum 100 characters
- cardValue: REAL NOT NULL
- points: INTEGER NOT NULL

Use the exact column names above. Add CHECK constraints for required lengths and numeric values.

Do not create USER, REDEMPTION, login, session, or authorization functionality.

Provide the complete SQL for schema.sql and explain each table and its constraints. Do not create seed data.

## AI Support

When using GitHub Copilot, I was able to type the final format I had in mind for the homework assignment, and Copilot generated the code.
While going through each line of code, I could then check the prompts against class materials and online resources to understand what 
was being done. Ultimately, Copilot helped me understand and implement PHP, SQLite, and reusable validation. 
While GitHub provided the code, I was still responsible for reviewing the output and validating that the application worked as required 
and met the assignment's requirements. 

## AI Suggestion 

One of the revisions I made to the code was to the seed data. Initially, Copilot generated fictional names for the gift cards, but I 
wanted to ensure that all AirAsia assignments were aligned. After the output from Copilot and my review, I went through and had the AI
change the gift card names to AirAsia Silver, Gold, and Platinum to reflect the previous weeks. This consistency helps me keep 
everything aligned and ensures that if the code were to build on itself week to week, it would use the same nomenclature.
